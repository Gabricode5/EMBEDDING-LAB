# EMBEDDING-LAB
Construis en trois semaines le moteur d’intelligence sémantique d’un agent IA. Entraîne un modèle d’embeddings capable de comprendre les relations entre conversations, décisions, actions et personnes.

Comment entraîner des embeddings spécialisés capables de relier les questions des utilisateurs
aux bonnes informations, de distinguer des relations sémantiques fines et d'alimenter un agent
qui répond, construit des dossiers et prépare des actions pertinentes ?
Le système devra traiter quatre difficultés :
1. Pertinence : retrouver les éléments utiles à une demande, même si les mots employés sont
différents.
2. Précision sémantique : différencier proposition, décision, annulation, contradiction, engagement
et simple mention.
3. Contexte : relier des informations dispersées entre plusieurs conversations et conserver leur
provenance, leur date et leur statut.
4. Intention et destinataire : comprendre si l'utilisateur veut une réponse, une synthèse, un dossier,
une tâche ou un brouillon d'e-mail, puis déterminer sur quelles informations et vers quels
destinataires cette action doit porter.
